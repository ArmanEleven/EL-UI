# EL-UI Windows UI Preview

This is an isolated UI-only prototype for testing the proposed Eleven visual direction on Windows. It is not the production EL-UI implementation and is not connected to Senai/3x-ui or Xray.

## Run
Open `index.html` in a browser. No runtime or internet connection is required.

## Limitations
No real authentication, admin roles, inbound/client operations, quotas, audit logs, database, or Xray integration are implemented here. The full integration must be built against the actual source tree and validated with tests.

The full downloadable preview package includes a Windows launcher and documentation.
