This archive contains the full source tree, frontend dependencies, generated frontend build, and a Linux amd64 x-ui binary.
The secondary-admin portal includes safe inbound visibility, client creation, an owned-client list, and connection links/QR codes.
Per-admin TOTP enrollment, login verification, owner reset UI, and the "x-ui admin reset-2fa -username NAME" command are included.
The release gate runs frontend formatting, type checking, tests, Storybook build, Go lint/tests, race tests, and packaging verification.
The login code field remains optional in the browser so unenrolled secondary admins can reach their required enrollment screen.
Go lint also checks that invisible Unicode formatting characters are escaped in source literals.
No .env file, database, private key, or runtime credential is intentionally packaged.
